## REQUISITOS                   
 
## REQUISITOS FUNCIONALES

## RF-01. INICIO
El sistema deberá contar con una página de inicio donde se presente el propósito de AulaLógica Web y se permita acceder a sus contenidos.

## RF-02. MÓDULOS DE APRENDIZAJE
El sistema deberá incluir seis módulos:

• Algoritmos y estructuras de pensamiento.
• Pseudocódigo y diagramas.
• Java básico.
• Estructuras condicionales.
• Ciclos.
• Validación y pruebas.

## RF-03. CONTENIDO DE LOS MÓDULOS
Cada módulo deberá incluir una explicación breve, un ejemplo resuelto, una práctica y retroalimentación.

## RF-04. PRÁCTICAS EN JAVA
El sistema deberá incluir tres prácticas procesadas con Java:

• Una de estructuras de selección.
• Una de ciclos.
• Una de validación o cálculo.

## RF-05. EVALUACIÓN
El sistema deberá incluir una evaluación de mínimo 10 preguntas, mostrando el puntaje y la retroalimentación.

## RF-06. GLOSARIO
El sistema deberá incluir un glosario con mínimo 15 conceptos relacionados con fundamentos de programación.

## RF-07. INFORMACIÓN DEL EQUIPO
El sistema deberá mostrar los integrantes del equipo, sus roles, aportes y créditos.

## RF-08. VALIDACIÓN DE DATOS
El sistema deberá validar campos vacíos y valores fuera del rango permitido.

## RF-09. ACCESIBILIDAD
El sistema deberá considerar características básicas de accesibilidad para facilitar su utilización.

## RF-10. DOCUMENTACIÓN
El proyecto deberá contar con documentación, evidencias, pruebas, arquitectura y trazabilidad de los aportes realizados en GitHub.
