## PROBLEMA

Los estudiantes que están iniciando en programación pueden presentar dificultades para comprender los fundamentos de la programación, especialmente al interpretar algoritmos, pseudocódigo, diagramas de flujo, estructuras de selección, ciclos y conceptos básicos de Java.

Por esta razón, se propone desarrollar AulaLógica Web, una aplicación web educativa que permita presentar estos contenidos de una manera clara y ordenada, mediante explicaciones breves, ejemplos resueltos y prácticas interactivas con retroalimentación.

## USUARIO OBJETIVO

El usuario objetivo es el estudiante que está iniciando el aprendizaje de programación y necesita comprender los fundamentos de la lógica de programación y Java mediante explicaciones, ejemplos y ejercicios prácticos.

## OBJETIVO

Diseñar y desarrollar una aplicación web educativa que facilite el aprendizaje de los fundamentos de programación mediante contenidos explicativos, ejemplos, prácticas y retroalimentación.

## NECESIDAD QUE SE BUSCA SOLUCIONAR

La aplicación busca proporcionar un espacio donde el estudiante pueda aprender, practicar y comprobar su comprensión de los fundamentos de programación de forma organizada e interactiva.
